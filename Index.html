SGP4 Processing

SGP4 means Simplified General Perturbations 4.

It is an orbital propagation model used with TLE data to estimate satellite positions over time.

  • Relative motion information
  • Orbital data uncertainty
  • Data quality and update time
  • Operator review and confirmation
